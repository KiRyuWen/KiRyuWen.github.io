# KiRyuWen.github.io

Vue 3 + Vite + Tailwind. Dark monospace theme. See README.md for full project docs.

## Key rules
- To add a project: edit only `src/data/projects.js` — cards and detail pages are data-driven
- To add a blog post: edit only `src/data/posts.js` — same pattern; body is a block array (see README)
- Design intent: keep it minimal

## Commands
- `npm run dev` — local dev
- `npm run deploy` — build + push to gh-pages
